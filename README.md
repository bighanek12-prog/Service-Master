\# Service Master



Service Master is a web-based household service management system developed using PHP, HTML, CSS, JavaScript, Bootstrap, and MySQL.



\## About the Project



The system is designed to help users request and track household services such as:



\- Cleaning Services

\- Plumbing Services

\- Electrical Services

\- Pest Control Services

\- Home Security Services

\- Home Maintenance Services

\- Appliance Repair Services

\- Home Energy Services



The project also provides an admin-side workflow for managing service requests and assigning work to technicians.



\## Features



\### User



\- User registration

\- User login

\- Browse available services

\- Submit service requests

\- Provide service and contact details

\- Track submitted service requests

\- View assigned technician details

\- Print assigned work details



\### Admin



\- Manage service requests

\- Add requesters

\- View request details

\- Assign service requests to technicians

\- Manage assigned work orders
